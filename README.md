# AI Chat Assistant

A modern AI chat interface with a beautiful UI.

## 🌐 Live Demo

Visit the website at: **https://tonda9.github.io/AI-website/**

## Features

- 🤖 Modern chat interface with AI assistant
- 💬 Beautiful message bubbles with animations
- 📱 Responsive design for mobile and desktop
- 🎨 Glass-morphism UI with gradient backgrounds
- ⚡ Real-time typing indicators

## Deployment

This website is automatically deployed to GitHub Pages when changes are pushed to the `main` branch.

### Manual Setup

To enable GitHub Pages for this repository:

1. Go to repository **Settings** → **Pages**
2. Under "Build and deployment", select **GitHub Actions** as the source
3. The workflow will automatically deploy your site

## Development

Simply open `index.html` in your browser to test locally, or use a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080` in your browser.
